# openobserve

[openobserve](https://github.com/openobserve/openobserve) is minimalistic observability tool that can collect logs and metrics

[openobserve.sh](./openobserve.sh) is a script to run `openobserve` from the same folder as this script, fully self contained

## Metrics Dashboard

[node_exporter_metrics](./NodeExportDashboard.json) - Simple system dashboard with CPU, Memory, Network and Disk panels
